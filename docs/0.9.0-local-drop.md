# Potato Mapper 0.9.0 — local Seasonal Studio drop

Implemented and locally packaged October 29, 2026. Public GitHub release remains 0.8.8 until a separate publication. Microsoft Store certification and physical-projector acceptance have not occurred.

## Try it

The existing desktop shortcut opens `app/PotatoMapper.exe`, now selecting `app/versions/0.9.0`. Previous installed runtime 0.3.0 remains available. File → Examples includes Seasonal Studio, Connected Skeleton, Wizard Duel and Shared Snowfall. The running editor starts on Seasonal Studio; projector output remains off.

Direct downloadable package: `out/releases/PotatoMapper-0.9.0-windows-x64.zip`. Extract the entire folder, then run its root PotatoMapper.exe. No development tools or GitHub login are needed.

## Changes

- Persistent surfaces with Map / Content / Connections task tabs, compact output controls and expandable display/entrance details.
- Settings → Appearance: Classic 1, Halloween, Autumn and Christmas. Theme/category preferences do not modify projects. A searchable seasonal browser applies stable animation IDs explicitly; hiding a category never disables saved content.
- Four native 24-second scenes: Hollow Crown, Lantern Keepers, Midnight Workshop and Shared Snowfall. Original IDs 0–18 and the praised ghost helper/branches remain unchanged. New scenes expose useful density, motion, size and palette controls.
- Previewed partial-edge Connect, optional source-edge fitting, Disconnect and optional translation ties. Target geometry stays fixed. Invalid/folding/coarse fits are rejected; hidden/transparent boundaries and independent touching panels do not create accidental passages.
- Shared exterior walking skeleton, plus an original coordinated cartoon wizard duel. The actors use one scene clock in preview/output, respect mapped clipping, visibility, opacity, brightness, entrance and blackout. Actor size/speed are currently authored constants; their positions react to the mapped geometry. More detailed actor editing remains future work.
- Connections/new scenes save as version 2. Conversion retains an exact permanent v1 recovery copy; recovery-name collisions get a content-addressed filename. Old runtimes reject v2; rollback never forwards an incompatible project. Concurrent external changes block overwrite and request Save as.
- Direct and Store profiles share the editor. Store identity selects a writable Documents project library and cache log, disables the portable updater/rollback and skips launcher maintenance. Store packaging includes only known runtime binaries, repository examples/notices and logos; project/media libraries stay outside the package.
- Build/package scripts reserve storage headroom and enforce the 1,500,000,000-byte project cap.
