# Potato Mapper 0.9.1 feature access

Source reachability audit, October 29, 2026. Compared the 0.9.0 `src/main.cpp` at `2f20536` with the final Studio source and unchanged `src/dynamic-ui.h`. No mapping, media, output or maintenance feature was found without a reachable control. This is a source audit; it does not claim every action was manually exercised or physically projected.

| Existing feature | Access in Studio | Result |
| --- | --- | --- |
| New, Open, Save, Save as | File menu; header Open/Save; existing keyboard shortcuts | Retained |
| Recent projects, app/Projects folders, examples | File → Recent projects / Open app folder / Open Projects folder / Examples | Retained, including all twelve existing example entries |
| Undo / Redo | Header icons, Edit menu, existing shortcuts | Retained |
| Add, duplicate, delete, layer order | Surfaces → + Surface; bottom icons with Duplicate / Delete / Back / Forward tooltips; Add also in Edit | Retained |
| Rename, visibility, locking, clear content | Double-click surface or right-click → Rename; row eye/lock; Map → Visible / Lock position; Content → Media → Clear media or surface context menu | Retained; Clear preserves mapping and Undo |
| Corners, mesh, subdivisions, reset, view navigation | Stage Select / Corners / Mesh; Map → Edit / Grid / Reset mesh / Fit view; stage Fit / zoom; wheel, pan and nudge shortcuts | Retained; toolbar and Map edit state synchronized |
| Load/drop images or video; media fit | File → Load media, Content → Media → Load media, surface context menu, or canvas drop; Map → Media fit | Retained |
| Video play/pause, restart, seek and mute | Content → Media, shown for selected video | Retained; separate from whole-scene actor playback |
| Brightness, opacity, blend and reset | Content → Surface appearance | Retained, including Normal / Screen / Add |
| Individual animations and browsing | Persistent Library search/category → select → Apply to surface, or drag onto a mapped surface; Content → Replace from library; Edit → Potato FX | Retained, stable IDs 0–22; filtering remains read-only |
| Animation speed, size and pause | Content below the selected animation preview | Retained, shown for an assigned animation |
| Animation selector, density, flow, angle, colour, soft edge, reverse | Content → More controls | Retained; scene-specific labels still update. For Media/white grid, choose an animation in Library first; per-animation controls then appear |
| Dynamic FX and all its settings | Scene → Dynamic FX; Edit → Dynamic FX opens and scrolls to it | Retained: effect, speed, shapes, glitch, snake width, cell size, palette, pause, membership, all-visible, Replay intro and Skip to ambient |
| Connect, fit edge, disconnect and tied movement | Stage Connect opens Connections; Connections controls; surface context menu Connect / Disconnect | Retained; Connect is a command and preserves the active editing tool |
| Walking skeleton and wizard duel | Scene → Whole scene actors | Retained; new speed/size and footer actor Play/Pause supplement the existing toggles |
| Themes, reduced interface motion and special events | Settings → Appearance; Settings → Special events opens the seasonal Library | Retained; settings remain separate from project content |
| Destination, Start, Stop, Blackout | Always-visible header destination / Start output / stop icon / Blackout; B shortcut; Esc stops output | Retained; safety controls are outside toolbar overflow |
| Display refresh/settings, output status and Potato Scan | Header gear → Output details: Refresh displays, Display settings, status/help, Play entrance, Skip, On output start | Retained in a nonblocking popup |
| Updates, previous runtime, guide, releases and About | Help → Check for updates / Use previous app version / Quick guide / GitHub releases / About | Retained with existing Store restrictions, restart/save prompts and incompatible-project rollback guard |

The old nested browser's Cancel/collapse action is replaced by a persistent resizable Library. Browsing still leaves the project unchanged until Apply or a drop. No runtime source was changed for this audit.
