## Important boundary

This implements the approved appearance, but **does not complete native desktop frosting**. Real clear desktop alpha remains the shipping path. The browser can blur its own backdrop; that is not evidence of native Windows blur. Isolated legacy accent, system transient Acrylic, DesktopAcrylicController and raw host-backdrop tests returned solid fills even though the required policies/support were enabled. Enabling whole-client alpha did not resolve the native-only failure. The composition marker rendered, so the exact input/attachment cause remains undetermined. The attempted inactive test mixed legacy SetTarget with a newer configuration API and was inconclusive.

Do not integrate the experimental controller or its Windows App Runtime dependency. A future native conformance proof must show changing, blurred external detail with readable controls and an opaque OpenGL canvas before integration. No Qt rewrite is justified by these results.
