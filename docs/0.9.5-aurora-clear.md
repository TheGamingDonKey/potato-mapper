## Rendering boundary

`src/aurora-glass.h` owns the two stationary colour fields and their pane rendering. `src/material.h` and `src/material-menu.h` apply them to the existing widgets, owned dialogs and real popup menus. `src/style.h`, `src/appearance.h`, `src/main.cpp` and the shared widget/icon helpers provide the controls, preference actions and colour treatments.

Transparency means seeing **app-owned background artwork through the interface chrome**. These profiles do not capture the operating-system desktop, other applications, the animated mapping canvas or projector output. Their menus use the same stationary environment without opening-time editor capture. Windows still supplies the caption frame and native file picker. This is Qt-rendered glass, with no claim of native DWM or Apple Liquid Glass integration.

The shared environment is capped at one million pixels and the pane cache at 16 MiB. Soft pane images are capped at 512,000 pixels each; text, icons and rims retain native resolution. Pointer light is local and has no animation timer. The existing **Reduce interface motion**, **Reduce glass transparency**, and **Increase glass contrast** preferences apply to both profiles; automatic synchronization with Windows accessibility settings is not claimed.
