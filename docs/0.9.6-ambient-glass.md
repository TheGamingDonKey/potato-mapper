## Use the theme

Select **Settings → Appearance → Interface theme → Ambient Glass 1**. Under **Settings → Appearance → Ambient Glass**, choose **Clear glass** or **Smoked glass**, toggle **Pause background motion**, or open **Adjust background…**. The dialog has Speed (0.2–1.2×), Light (20–100%), both glass options, Pause and Reset background. Defaults are Smoked, 0.5× speed and 65% light. Settings persist as app preferences independently of saved mappings.

The familiar 0.8.8 toolbars, output controls, surface sidebar and mapping canvas stay in place. Mapping, animation, Connections, actors, context actions including Delete, Undo/Redo and project compatibility remain. Classic 1, Material, Windows Liquid Glass 1, AuroraClear 1 and Transparent Glass 1 remain selectable.

## Rendering and behaviour

Original teal, copper and plum light fields drift beneath the existing Qt glass controls, dialogs and menus. The artwork is procedural; no Windows wallpaper is included. `src/ambient-glass.h` provides the shared light field; `src/material.h` controls its clock and repaint lifecycle; `src/ambient-controls.h` and `src/appearance.h` provide controls and preference storage. The renderer uses the existing C++17/Qt stack without new dependencies.

The light environment is bounded to 800×500 pixels and uses cached light textures. Its timer is capped below 30 ticks per second. Hidden/minimized windows pause, and **Reduce interface motion** also stops the background. The existing reduced-transparency and increased-contrast preferences remain available. Motion does not create Undo entries or mark a mapping dirty. The mapping canvas and projector render remain separate from the backdrop. This is app-rendered glass, not desktop capture or native Windows/Apple material integration.
