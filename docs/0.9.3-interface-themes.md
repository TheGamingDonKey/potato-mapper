## Interface design and accent are separate

Use **Settings → Appearance → Interface theme**:

| Theme | Design |
| --- | --- |
| Classic 1 — 0.8.8 | The original tagged 0.8.8 stylesheet: flat legacy controls, mint interaction colour and opaque menus. Material painting and backdrop capture are bypassed. |
| Material — Windows 11 | The approved painter-based interface, refined with stable foundation/content layers, restrained light/rims, clearer local hover/press/disabled/focus states and frosted transient menus. |

Both run the same current software, layout and features. Switching changes the real widgets' presentation in place; it preserves project state and output. This is a choice between interface designs rather than a palette selector. The old seasonal colours remain available separately under **Material accent**, remembered while Classic keeps its original styling.

The new `ui/interfaceTheme` preference defaults to Material for existing users. Accent reads `ui/accent`, falling back to legacy `ui/theme`; an old `ui/theme=classic1` therefore preserves the already-installed Material appearance. Explicit choices persist, and the old palette key remains compatible with the prior runtime. Project files have no theme migration.

## Material refinements

Persistent surfaces are calmer and less grainy, with consistent layered controls. Entire panels no longer brighten when the pointer enters empty space; hover/press response belongs to controls. Fields retain clear focus treatment, and menu frost remains bounded to one editor sample per opening. No animation timer, per-frame blur or new dependency was added. Existing Reduce interface motion and independent scene playback remain intact.

The design follows the separate persistent/transient roles in Microsoft's [materials guidance](https://learn.microsoft.com/en-us/windows/apps/design/signature-experiences/materials) and [layering guidance](https://learn.microsoft.com/en-us/windows/apps/design/signature-experiences/layering). The implementation uses existing Qt painting, not native DWM Mica/Acrylic. Models, projection rendering, formats and storage logic are unchanged.
