# 0.9.7 — Four studio themes

Implemented, packaged, tested and installed locally on November 1, 2026. Current: 0.9.7; retained rollback: 0.9.6. Lumen is selected with the recovered mapping open. Eight final deployed suites, the 229-assertion studio diagnostic at two display scales, three single-quad smoke regressions and the real installed rollback/reopen sequence pass. Storage is approximately 0.81 GB; the DEVELOPMENT.md handoff records the blocked cleanup copy included in that total.

Shane approved the revised November 1 studies for native implementation. Lumen Atelier, Nocturne Cinema, Sienna Studio and Tidal Lens replace the menu choices Transparent Glass 1 and Windows Liquid Glass 1. Tidal's current study is included; further visual refinement is explicitly deferred.

## Controls and compatibility

Use **Settings → Appearance → Interface theme**. Classic 1, Material, AuroraClear 1 and Ambient Glass 1 remain available. Saved `transparentglass1` selections migrate to `lumenatelier1`; `liquidglass1` migrates to `nocturnecinema1`. Seasonal Material accents remain separate.

**Settings → Appearance → Theme motion** offers Pause and Adjust background. Speed (0.2–1.2×), Light (20–100%) and Pause share the existing Ambient preference storage. The Ambient submenu retains its Clear/Smoked controls. Reset in Theme motion preserves that hidden glass choice. Reduced motion, reduced transparency, increased contrast and minimized windows stop the new background clock.

The existing C++/Qt interface retains the 0.8.8 toolbar order, projector controls, left surface sidebar, mapping canvas, menus and feature locations. Theme changes reuse the actual widgets and actions. Projects, meshes, media references, undo history and projector rendering are independent of theme settings.

## Native materials

| Theme | Material and controls | Motion |
|---|---|---|
| Lumen Atelier | Porcelain optical panels, warm/cool light, blue primary actions and coloured lens glyphs | Slow broad reflection |
| Nocturne Cinema | Smoked blue-black panels, flat instrument keys, pale primary action and warm highlight | Restrained moving light planes |
| Sienna Studio | Cream ceramic panels, copper seams/actions and a dark ink command bar | Soft warm studio light |
| Tidal Lens | Seaglass panels, circular glyph lenses, deep ink actions and citron selection | Broad caustic reflections |

One original procedural light field is shared by each theme's panels, menus and dialogs, capped at 800×500 pixels. The existing chrome clock is capped near 30 Hz. The painter never captures the desktop or samples the mapping/projector canvas. These are app-rendered materials, not native Apple Liquid Glass or Windows DWM effects. No new dependency or framework was introduced.

## Verification and update evidence

Evidence is kept under `out/studio-themes/` rather than in saved-project folders. Native captures include all four real themes. The new diagnostic covers menu removal/migration, widget/action identity, labelled commands, saved state and undo, projection pixels, real animated/paused chrome, bounded cache, accessibility fallbacks, background controls, Reset, minimize/resume and right-click Delete/Undo.

Independent review caught and corrected Sienna's pale toolbar-button base and Theme motion Reset changing Ambient's hidden glass option. During real launcher checking, an existing generic `--smoke` diagnostic wrote `mesh[4]` into a loaded four-point quad. It could corrupt memory in both old and new runtimes. The diagnostic now normalizes its disposable scene to a two-cell/nine-point mesh before that deformation. Production mapping and file loading were not changed. Unmodified 0.9.6 is checked using a compatible nine-point synthetic fixture.

The original open mapping was saved separately as `app/Projects/Recovered before four themes/Unsaved before 0.9.7.pmap` before restarting. Existing source, Git history, project/media files and retained releases are preserved. Recent-project indexing may change when saving/opening a recovery copy; saved project/media bytes are verified separately.

Final installed version, verification results, storage and remaining limitations are recorded in the current DEVELOPMENT.md handoff. This update does not publish a GitHub release, submit a Store package or establish physical-projector compatibility.
