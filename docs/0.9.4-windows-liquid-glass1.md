## Rendering and interaction

`src/liquid-glass.h` provides a shared procedural studio environment, bilinear edge displacement, smoked absorption, curved highlights, pearl meniscus and lower caustic. `src/material.h` applies it to existing editor widgets and owned dialogs. `src/material-menu.h` lenses a bounded real editor sample at menu edges once per opening; action text sits on a stable dark bed. QSS supplies coherent controls, selections, sliders, checks, scrollbars and tooltips. Local labels were adapted without changing their legacy styling or metrics.

This is **app-rendered optical glass**, not native Apple Liquid Glass or a Windows DWM desktop backdrop. Persistent chrome refracts a generated light field, not live scene content or other applications. Windows still owns the caption frame and native file picker. There is no new toolkit, dependency download, background image, continuous screen capture or shimmer timer.

The field is at most one million pixels. The optical plate cache remains 16 MiB. Soft substrates use logical 1× resolution with a 512k-pixel cap; vector rims and Qt foregrounds retain native resolution. Pointer light is local and timer-free. Owned dialog movement repaints the shared field correctly. **Reduce interface motion**, **Reduce glass transparency**, and **Increase glass contrast** are app preferences; no automatic Windows accessibility synchronization is claimed.

The familiar project/output bands, left surface list and scrolling sections, and right mapping canvas remain in place. Media, Appearance, Potato FX, Dynamic FX, Mapping, Connections, whole-scene actors, all 23 animations and the browser remain reachable. The real surface menu retains Load, Choose animation, Clear, Connect/Disconnect, Rename and Delete with Undo. Models, scene formats, mapping geometry and projection shaders were not changed.
