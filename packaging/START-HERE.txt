POTATO MAPPER

1. Extract the whole ZIP to a folder on your computer.
2. Open PotatoMapper.exe inside that folder.
3. Connect your projector. Press Windows + P and choose Extend.
4. Add a surface, drop in an image/video, and move its corners or mesh points.
5. Select your projector under PROJECTOR OUTPUT and click Start output.

Keep PotatoMapper.exe, installation.txt, current.txt and the versions folder
together. The versions folder contains the editor and its runtime libraries.
You do not need Visual Studio, Qt, Python, or a GitHub account to run this build.

For 64-bit Intel/AMD Windows 10 (22H2) or Windows 11 with an OpenGL 3.3 Core
graphics driver. This is not a macOS, Linux, or native Windows ARM build.

Save mappings using the app's Save command. Projects is the default location.
Opening an external project can collect a portable copy and its media there;
the original files remain available. Keep Projects when moving the app folder.

Right-click a surface (or its list entry) and choose Clear media to return it
to the white grid. Its mesh stays in place. Ctrl+Z restores the media.
Double-click its list entry to rename it. Help has a quick guide and About.

Drag the divider beside the surface list to resize the sidebar. Click Media,
Appearance, Potato FX or Mapping headings to expand/collapse their controls.
Appearance has brightness and opacity sliders for the selected surface.
Potato FX offers individual procedural animations. Dynamic FX coordinates
several surfaces with Hot-Ass Potato or Potato Focus. File > Examples opens
ready-made three-surface demos. Choose participating surfaces in Dynamic FX;
select Off to restore their original content. Replay intro restarts the snake.

HALLOWEEN / FALL
File > Examples > October Porch combines Pumpkin Mischief, Ghost Parade and
Rainlit Window. Individual examples show glowing pumpkins, lantern-led ghosts
and a quiet autumn window. These also appear in Potato FX > Animation.
Start with Original colour, Speed 100% and Scene size 24%; the examples carry
their own Density/Flow defaults. Pause and Reverse use twelve-second loops.
The new Halloween/fall effects need 0.8.8 or later; older apps can replace them
when saving a new mapping. No media download is needed.

THANKSGIVING / AUTUMN
File > Examples > Maple Supper opens warm maple leaves, pumpkins and a potato
in an autumn scarf. Harvest Lanterns is a quieter candle-and-amber scene.
Use Potato FX > Animation to put either effect on your existing mapped surface.
Start with Original colours, Speed 100%, Scene size 24% and Flow 70%.

UPDATES
Use Help > Check for updates to download a newer stable Windows release.
Save your work when asked, then let the launcher install and reopen the app.
The previous app version remains available under Help > Use previous version.
If an older copy reports "outside the portable launcher layout", save and close
it, then open PotatoMapper.exe in the main extracted folder and check again.
Point shortcuts to that launcher. Extract the full ZIP if launcher files are missing.
Updates preserve projects/media outside versions and .updates. Do not save
personal files inside those two managed folders. Media remains linked.
The installed editor also refreshes the root launcher from its release payload.
Previous launcher copies and readable maintenance errors live in .maintenance.
Keep the versions folder intact for recovery and rollback. If current.txt is
missing, invalid, or selects a damaged current runtime with an inventory, the
launcher selects a complete retained application.
If PotatoMapper.exe itself is missing, extract a complete app ZIP into a new
folder, or open versions/<version>/PotatoMapperApp.exe with --install-root pointing
to the original app folder so its native maintenance helper can restore it.

IF YOU ALREADY HAVE VERSION 0.2.0
Close Potato Mapper. Extract this ZIP, then copy its contents into your existing
app folder, replacing PotatoMapper.exe when Windows asks. Keep your existing
mapping files and media. Do not delete the old folder. Open PotatoMapper.exe.
This one-time upgrade adds the launcher; future updates can use the Help menu.
